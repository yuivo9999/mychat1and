# MyChat Android

This module turns the existing Vite/React UI into a native Android application shell.

## Architecture

React/Vite UI
-> Android WebView
-> `window.MyChatAndroid`
-> Chaquopy
-> Python 3.13

The TypeScript execution adapter already calls `window.MyChatAndroid.executePython(code, timeoutMs)` when this bridge exists.

## Build

Requirements:

- Android Studio / JDK 17
- Android SDK 37
- Node.js + npm
- Gradle wrapper generated by Android Studio or `gradle wrapper`

From the repository root:

```bash
npm install
cd android
gradle assembleDebug
```

The Android build invokes the existing Vite build and copies `dist/` into the APK assets.

## Python

Chaquopy 17.0 embeds Python 3.13. The bridge accepts Python source directly, so the AI does not need to generate `python -c`.

Example:

```python
print("Hello from MyChat Android")
```

The bridge returns stdout, stderr, exitCode and error to the existing TypeScript execution adapter.
